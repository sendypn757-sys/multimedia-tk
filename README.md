## Deskripsi
Presentasi 15 slide yang menjelaskan manfaat multimedia bagi anak usia dini sekaligus menjadi media belajar interaktif. Anak dapat bermain game warna, berhitung, menebak suara hewan, memainkan piano, dan menggambar. Dibuat dengan HTML, CSS, dan JavaScript murni tanpa framework.

## Struktur slide
1. Judul | 2. Tujuan | 3. Apa itu multimedia | 4. Kenapa belajar jadi seru | 5. Manfaat bagi anak | 6. Cara merancang untuk usia 5-7 tahun | 7-9. Game warna, berhitung, tebak suara hewan | 10. Piano | 11. Menggambar | 12. Contoh media belajar anak (3 studi kasus) | 13. Pesan untuk guru dan orang tua | 14. Penutup dan bintang | 15. Referensi

## Cara membuka / menjalankan
- **Online:** buka link live di atas.
- **Lokal:** unduh repo lalu buka `index.html` di browser. Tidak perlu instalasi.
- **Navigasi:** tombol besar di bawah layar, titik slide, atau panah keyboard.
- **Suara:** tombol 🔊 membacakan slide (suara bawaan browser berbahasa Indonesia), dan 🔔 mematikan suara.

## Fitur interaktif
Kartu pengenalan multimedia, tiga game pilihan dengan bintang dan konfeti, kartu balik studi kasus dengan video YouTube, setiap game dibatasi 10 soal dengan skor akhir, piano dengan Web Audio, kertas menggambar, bacaan otomatis, serta animasi dan efek hover. Responsif untuk ponsel, tablet, dan desktop.

## Tools
VS Code, Git dan GitHub, GitHub Pages, Google Fonts (Baloo 2), Unsplash, Lighthouse dan WAVE.

## Design decisions
- Empat warna tema: kuning `#FFD93D`, merah muda `#FF8FA3`, hijau mint `#7EE2A8`, dan biru langit `#7CC8FF`, dengan teks biru tua `#2B2D42`. Warna pada game warna dan kertas gambar adalah isi pelajaran, bukan warna tema.
- Satu font bulat dan ramah anak, Baloo 2.
- Tombol besar, petunjuk bersuara, dan umpan balik langsung karena anak 5-7 tahun belum lancar membaca dan butuh respons cepat.
- Tanpa iklan, tanpa data pribadi, tanpa tautan keluar.
